# Partner Pulse — Berlitz Case Study

A one-page, interactive product case study built for a Senior Product Manager application to Berlitz. Concept: an AI-powered reconciliation and anomaly-detection layer unifying billing, compliance, and performance data across Berlitz's global partner network.

Self-contained, no build step, no dependencies.

## Publish on GitHub Pages

1. Create a new repo (e.g. `partner-pulse-case-study`) and push this folder's contents to it.
2. In the repo, go to **Settings → Pages**, set source to the `main` branch, root folder.
3. GitHub will publish it at `https://<your-username>.github.io/<repo-name>/`.

## Files

- `index.html` — the full case study (all HTML/CSS/JS inline, single file)

## Notes

- All figures inside the case study are clearly labeled as illustrative or estimated. No real Berlitz internal data is used or implied anywhere.
